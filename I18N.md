# i18n (RU/EN)

Механизм перевода интерфейса. Язык определяется автоматически:

1. `?lang=ru|en` в URL (приоритет)
2. `localStorage.pingusha_lang` (выбор пользователя)
3. `navigator.language` браузера (fallback)

## Как добавить перевод

1. Найди текст в `app/index.html` и добавь атрибут `data-i18n="ключ"`:
   ```html
   <button data-i18n="logout">ВЫЙТИ</button>
   ```
2. Добавь ключ в словарь `I18N_DICT` внутри `index.html` (блок в конце файла)
   для `ru` и `en`.
3. Обнови `locales/ru.json` и `locales/en.json` (используются для документации и
   будущих расширений).

## Что пока не переведено

- Динамические строки в JS (плитки «N в сети», модалки, уведомления)
- Тексты Telegram-бота (отправляются на русском)

## Смена языка в работающей инсталляции

```bash
# в .env
LANG=en
# и перезапуск
docker compose up -d
```
