# Pingusha

**Версия: 1.0.0**

🌐 [English](README.md) | [Русский](README.ru.md)

Self-hosted монитор сети: **карта объектов, дерево устройств, Telegram-уведомления**.

Создан для мониторинга камер, регистраторов и сетевого оборудования на удалённых объектах.
Полностью автономен (работает без внешних зависимостей — удобно для России).

## О проекте

Я системный администратор и обслуживаю много удалённых объектов. Долго искал простую систему мониторинга, которая по ICMP-запросам отслеживает работоспособность оборудования. Zabbix оказался слишком громоздким, а чего-то более простого не нашлось — пришлось напрячь нейронку.

Pingusha присылает алерты о недоступности устройств, а благодаря дереву сразу видно, где вытащили этот чертов кабель из порта или отключили питание коммутатора.

## Возможности

- 🗺️ **Карта объектов** с кластеризацией (зелёное кольцо / красная дуга = доля проблем)
- 🧱 **Плитки («Объекты»)** — проблемные объекты первыми
- 🌳 **Дерево устройств** (роутер → коммутаторы → регистраторы → камеры), порядок настраивается стрелками
- 🤖 **Telegram-бот**: привязка по ключу, уведомления об offline (собираются в одно сообщение, задержка настраивается), ежедневное контрольное сообщение (по умолчанию 10:00 барнаульского), кнопка «Контроль»
- 👥 **Роли**: админ / менеджер с правами на конкретные объекты
- 🔒 Защита от перебора паролей (5 попыток → блок 5 минут)
- 🌍 **Интерфейс RU/EN** (выбор при установке и в настройках)

## Установка (одна команда)

```bash
curl -fsSL https://github.com/tsodya/Pingusha/raw/main/install.sh | bash
```

Скрипт спросит язык (русский/english), опционально токен Telegram-бота,
сгенерирует пароль admin и поднимет всё через Docker.

### Ручная установка

```bash
git clone https://github.com/tsodya/Pingusha
cd Pingusha
cp .env.example .env        # задать TELEGRAM_TOKEN (опционально) и LANG
docker compose up -d --build
```

Откройте **http://localhost:45585**. При первом запуске создаётся **только admin** —
пароль генерируется установщиком (показывается в консоли) или берётся из `ADMIN_PASSWORD`.
Дефолтных паролей нет! Остальных пользователей создавайте в **Настройки → Пользователи**
(пароль admin смените сразу после входа!).

## Обновление

Одна команда (данные, пароль и токен бота сохраняются):

    curl -fsSL https://github.com/tsodya/Pingusha/raw/main/update.sh | bash

Скрипт делает автоматический бэкап БД (backups/), подтягивает код и пересобирает контейнер.
`.env` (пароль, токен) и база данных (volume `pingusha-data`) не затрагиваются.

## Настройка Telegram-бота

1. Создайте бота через [@BotFather](https://t.me/BotFather) → получите токен
2. Вставьте токен в **Настройки → Токен Telegram-бота** (админ)
3. В приложении: Настройки → Уведомления → «Открыть бота» → `/start` → вставьте ключ → «Привязать»
4. Нажмите «🧪 Тест», чтобы проверить доставку

## Бэкап

```bash
docker run --rm -v pingusha-data:/data -v "$PWD":/backup alpine tar czf /backup/pingusha-backup.tar.gz -C /data .
```

## Технологии

FastAPI + SQLite + vanilla JS + MapLibre GL. Один контейнер (python:3.12-slim).
